// How it works

You talk. One agent thinks. The right agents do the work.

Agent2 doesn't do the heavy lifting. It tells your chosen agent what else is on your Mac, runs whatever it hands off in parallel, and keeps the record.

1

Pick a source

Agent2 finds agent CLIs, API keys and desktop apps. You choose which one is the brain. Only you ever change it.

// Features

A small app with reach into every agent you have.

No Dock icon, no notch takeover, no Agent2 servers. A pixel bird in the menu bar and a shortcut you can hold from anywhere.

Menu bar

Always one click away

Click the bird for the chat. Right-click to switch source or open history.

Voice

Push-to-talk anywhere

Hold Control + Option, speak, let go. A quick tap opens the chat for typing.

Delegation

Real parallel hand-offs

Work fans out to Claude Code, Codex, Gemini, Cursor or an API model, and comes back combined.

History

Markdown you own

One .md file per conversation. Switch from Claude Code to Codex and your context comes along.

Detached

Tied to no vendor

Agent2 never switches the source on its own. You change it in Settings whenever you like.

Local

Your keys stay on your Mac

Subscriptions run through each vendor's own CLI. API keys live in the macOS Keychain.

// FAQ

Questions

Do I need an API key?

No. If Claude Code or Codex is installed and signed in with your Claude or ChatGPT plan, Agent2 uses that. API keys are optional and stay in your Keychain.

Where is my history stored?

In ~/Agent2/History by default, one Markdown file per conversation, grouped by month. You can move the folder in Settings → History.

Why does it ask for Accessibility access?

macOS only lets an app see a shortcut held in other apps, like Control + Option, when it has Accessibility access. Agent2 uses it for the shortcut and nothing else.

Is my voice sent anywhere?

Speech is transcribed by Apple's recogniser on your Mac where supported. Only the resulting text goes to the agent you chose.

macOS says it's from an unidentified developer.

Early builds aren't notarised. Right-click Agent2.app → Open and confirm once, or build it yourself with ./scripts/build-app.sh.
