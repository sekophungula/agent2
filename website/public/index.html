// how it works

You talk. One agent thinks. The right agents do the work.

01

Pick your source

Agent2 scans your Mac for agent CLIs, API keys and desktop apps. You choose which one is the brain — and only you ever change it.

02

Hold ⌃⌥ and ask

Speak from any app. Speech is transcribed on-device and sent to your source agent along with your recent conversation.

03

It delegates in parallel

The source hands self-contained briefs to the agents best suited — Codex for tests, Gemini for a 900-page PDF — then merges the results.

what the source agent writes
# Claude Code (your source) decides to split the job
I'll review the README myself and have Codex write the tests.

<delegate agent="codex">Add unit tests for src/parser.ts covering empty
input and nested blocks. Run them and report the results.</delegate>

# Agent2 runs Codex, feeds the result back, and saves it all to

Small app. Leverage over every agent you have.

No Dock icon, no notch takeover. A pixel bird up top, one click or one shortcut away.

Push-to-talk anywhere

Hold Control + Option, speak, let go. A quick tap opens the chat for typing instead.

Real delegation

The source agent fans work out to Claude Code, Codex, Gemini, Cursor or an API model — in parallel — and combines it.

Your keys, your Mac

Uses your Claude or ChatGPT subscription through their own CLIs, or API keys stored in the macOS Keychain. No Agent2 servers.

// faq

Questions

Do I need an API key?

No. If you have Claude Code or Codex installed and signed in with your Claude or ChatGPT plan, Agent2 uses those. API keys are optional and stay in your Keychain.

Where is my history stored?

In ~/Agent2/History by default, one Markdown file per conversation grouped by month. You can move the folder in Settings → History.

Why does it ask for Accessibility access?

macOS only lets an app hear a global shortcut like Control + Option held in other apps when it has Accessibility access. Agent2 uses it for the shortcut and nothing else.

Is my voice sent anywhere?

Speech is transcribed by Apple's on-device recogniser where your Mac supports it. Only the resulting text goes to the agent you chose.

The app says it's from an unidentified developer.

The first builds are ad-hoc signed. Right-click Agent2.app → Open, then confirm once. Or build it yourself from the GitHub repo with ./scripts/build-app.sh.
