Supported agents

CLIs, API keys and desktop apps.

Agent2 looks for these when it starts and whenever you click Scan again.

Command-line agents

AgentCommand Agent2 runsUses
Claude Codeclaude -p --output-format stream-jsonYour Claude plan
Codex CLIcodex execYour ChatGPT plan
Gemini CLIgemini -pYour Google account
Cursor Agentcursor-agent -pYour Cursor plan
OpenCodeopencode runWhichever provider you set up

Agent2 looks on your PATH plus the usual install folders: Homebrew, ~/.local/bin, npm, pnpm, Volta, Bun and Cargo globals.

API keys

Add an Anthropic or OpenAI key in Settings → Agents and it shows up as Claude API or OpenAI API. See API keys.

Desktop apps

The Claude and ChatGPT desktop apps are detected too. They can't run in the background, so Agent2 hands off to them: it copies your prompt and opens the app.
