Build from source

Compile Agent2 yourself.

Requirements

  • macOS 14 or newer
  • Xcode 16 or newer (Swift 5.10+)

Build the app

Clonegit clone https://github.com/sekophungula/agent2.git && cd agent2
Build./scripts/build-app.sh

This builds a universal release and writes dist/Agent2.app and dist/Agent2-macOS.zip.

Developer helpers

cd app && swift build
.build/debug/Agent2 --ask "summarise my week"     # one request, no UI
.build/debug/Agent2 --snapshot /tmp/agent2-shots  # render the UI to PNGs
.build/debug/Agent2 --export-assets /tmp/assets   # icons and logo SVGs
