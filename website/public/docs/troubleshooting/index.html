Troubleshooting

Fixes for common problems.

“Claude Code isn't signed in”

Run claude once in Terminal and sign in, then try again. The same goes for codex.

An agent isn't detected

Check it runs in Terminal, for example which claude. If it's installed somewhere unusual, link it into /opt/homebrew/bin or ~/.local/bin, then click Scan again in Settings → Source.

⌃⌥ does nothing

  • Open Settings → Voice & hotkey and check Accessibility shows Granted.
  • If you replaced the app with a new version, remove Agent2 from System Settings → Privacy & Security → Accessibility and add it again.
  • Make sure the shortcut is enabled in the same panel.

“Agent2” Not Opened

Agent2 isn't notarised by Apple yet, so macOS blocks the first launch. It isn't malware, and you only need to allow it once:

  1. Click Done in the warning. Don't click Move to Bin.
  2. Open System Settings and go to Privacy & Security.
  3. Scroll down to the Security section. You'll see “Agent2 was blocked to protect your Mac.”
  4. Click Open Anyway, confirm with your password or Touch ID, then click Open Anyway in the next dialog.

The Open Anyway button only shows for about an hour after the warning. If it's gone, open Agent2 again to bring it back.

Comfortable in Terminal? This does the same thing:

xattr -dr com.apple.quarantine /Applications/Agent2.app

Composio says it isn't installed

Install the CLI from the Composio docs, then click Refresh in Settings → Apps.

Still stuck?

Open an issue on GitHub with what you tried and what you saw.
