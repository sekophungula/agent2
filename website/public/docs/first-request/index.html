Your first request

Talk to Agent2 and watch it delegate.

Ask by voice

  1. From any app, hold ⌃ ⌥. After a moment you hear a soft tick and the notch (or the menu bar bird) turns into a green Listening pill. No window opens.
  2. Say what you want, for example: “Have Codex add tests to my project while you review the README.”
  3. Let go. The pill shows Working while your agents do it, then Agent2 tells you what it did, out loud.

Ask by typing

Click the bird in the menu bar, or tap ⌃ ⌥ briefly, then type at the > prompt and press Return.

Watch it work

While the agents work, the bar above the prompt shows what's happening, with a Stop button. Each hand-off appears as a row like this:

==> Agent2 → Codex CLI      DELEGATED
==> Codex CLI               ✓ DONE

Click a row to see the brief that was sent, or the result that came back. The source's final answer appears underneath.

Find it later

The conversation is saved as a Markdown file in ~/Agent2/History. Click the clock icon in the popover to browse and continue past conversations. See History.
