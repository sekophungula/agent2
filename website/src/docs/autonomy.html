Autonomy sets what command-line agents may do on your Mac. Choose it in Settings → Agents → What agents may do.

Levels

LevelClaude CodeCodex
Ask first (default)Default permissions: no edits or commands when run in the background-s read-only
Edit files in workspace--permission-mode acceptEdits-s workspace-write
Full access--dangerously-skip-permissions-s danger-full-access

Full access lets agents run any command without asking. Use it only for work you'd be comfortable running yourself.

The workspace

Agents start in ~/Agent2/Workspace unless you change it. Point it at a project folder to have agents work on that project.

Apps and messages

Whatever the level, agents are told to show you the exact draft of any email, post or message and wait for your yes before sending it through Composio.
