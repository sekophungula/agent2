API keys are optional. Use them if you'd rather pay per use than use a subscription CLI, or to give an API model the source role with full tool use.

Adding a key

  1. Open Settings → Agents → API keys.
  2. Paste an Anthropic key (sk-ant-…) or an OpenAI key (sk-…).
  3. Click Save and rescan.

Keys are stored in your macOS Keychain, never in a file.
