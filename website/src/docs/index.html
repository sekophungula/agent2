Agent2 is a macOS menu-bar app that sits in the middle of the AI agents you already use. It doesn't answer questions itself. You choose one agent as the source. Agent2 tells it which other agents and tools are on your Mac, runs whatever it hands off in parallel, and saves the whole conversation as Markdown that you own.

When to use Agent2

  • You pay for Claude Code, Codex or both, and want one place to ask that can use either.
  • You want one agent to split a job: Codex writes tests while Claude Code reviews the docs, and Gemini reads a long PDF.
  • You switch between agents and sessions and don't want your context to live inside any one of them.
  • You want your agents to act in Gmail, Slack, GitHub or social accounts through Composio.
  • You'd rather hold a shortcut and talk than open a terminal.

Who it's for

Anyone with a Claude or ChatGPT subscription that includes Claude Code or Codex, or with an Anthropic or OpenAI API key. You don't need to write code; the agents do. If you have no agent installed yet, start with Install.

What Agent2 is not

  • Not a model. Agent2 runs agents you already have, with your own sign-ins and keys.
  • Not a server. Nothing goes through Agent2's servers; there are none. Agents talk to their own vendors as usual.
  • Not tied to a vendor. Agent2 never switches your source by itself, and your history stays in plain files.
