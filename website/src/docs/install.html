Requirements

  • macOS 14 Sonoma or newer, on Apple Silicon or Intel.
  • At least one agent: Claude Code, Codex, Gemini CLI, Cursor Agent, OpenCode, or an Anthropic or OpenAI API key.

Download and open

  1. Download Agent2.dmg and open it.
  2. Drag Agent2 onto the Applications folder in the window that opens, then eject the disk image.
  3. Open Agent2 from Applications. Early builds aren't notarised, so the first time macOS shows “Agent2” Not Opened. Click Done (not Move to Bin).
  4. Open System Settings → Privacy & Security, scroll down to Security, and click Open Anyway next to “Agent2 was blocked…”. Confirm with your password or Touch ID, then click Open Anyway again.

You only do this once. Later versions open normally after you replace the app.

Agent2 appears in the menu bar as a pixel bird. There's no Dock icon.

Updating

From version 0.1.5, Agent2 updates itself. It checks GitHub shortly after it starts and every six hours; when a new version is out, a green Update strip appears at the top of the chat. Click it and Agent2 downloads the update, swaps it in and reopens. You can also use Settings → About → Updates or Check for updates… in the menu, and turn automatic checks off there.

Updates only install when Agent2 is in your Applications folder (not running from the disk image), and only if they're signed with Agent2's certificate. On 0.1.4 or earlier, download the latest version once from the download page.
