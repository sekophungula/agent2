Requirements

  • macOS 14 Sonoma or newer, on Apple Silicon or Intel.
  • At least one agent: Claude Code, Codex, Gemini CLI, Cursor Agent, OpenCode, or an Anthropic or OpenAI API key.

Download and open

  1. Download Agent2.dmg and open it.
  2. Drag Agent2 onto the Applications folder in the window that opens, then eject the disk image.
  3. The first time, right-click Agent2 → Open → Open. Early builds aren't notarised, so macOS asks once.

Agent2 appears in the menu bar as a pixel bird. There's no Dock icon.

Grant permissions

PermissionWhyWhen it's asked

Speech RecognitionTo turn your voice into text, on your Mac where supported.First time you talk

You can use Agent2 without any of these by clicking the bird and typing.

Install an agent

If Agent2 finds no agents, install one and sign in once in Terminal:

Claude Codenpm i -g @anthropic-ai/claude-code && claude
Codex CLInpm i -g @openai/codex && codex

Then open Settings → Source and click Scan again. Or add an API key instead; see API keys.
