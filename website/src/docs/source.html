The source is the agent Agent2 thinks with. It reads your request, does what it can itself, and hands the rest to other agents.

Choosing the source

On first launch Agent2 picks the first agent it can run in the background, usually Claude Code. After that, only you change it:

  • In the popover, click source: … and pick an agent.
  • Right-click the menu bar bird → Source.
  • Or open Settings → Source.

Why Agent2 never switches it

Agent2 is meant to be detached from any one vendor or session. If it silently changed your source, you'd lose track of whose subscription and settings a job ran under. So the source stays put until you change it, and your history stays the same either way.

Desktop apps as a source

The Claude and ChatGPT desktop apps can't be run in the background. If one is your source, Agent2 copies your prompt and opens the app so you can paste it. For delegation, pick a CLI agent or an API key.
