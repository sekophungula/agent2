Composio links your apps so agents can act in them. Agent2 drives the Composio command-line tool, which handles sign-in and stores the connections.

Set up

  1. Install the Composio CLI. Settings → Apps has an Install Composio button that opens the guide.
  2. Click Sign in with browser and finish signing in.
  3. Click Link on any app and approve access in your browser.

Already linked in Claude Code or Codex?

Agent2 checks whether Composio is already set up in Claude Code and Codex, and shows each as linked. If one isn't, Add to my agents sets Composio up in both.

What agents can do

CLI agents use Composio directly once it's added to them. API agents get composio_search and composio_execute tools through Agent2. Either way, agents are told to show you the exact draft and get your yes before sending or posting anything.
