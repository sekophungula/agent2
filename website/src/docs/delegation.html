Delegation is how the source splits a job. Agent2 tells the source which other agents are available and what each is good at; the source decides who does what.

How CLI sources delegate

Claude Code, Codex and the other command-line agents delegate by writing a tag in their reply:

I'll review the README myself and have Codex write the tests.

<delegate agent="codex">Add unit tests for src/parser.ts covering empty
input and nested blocks. Run them and report the results.</delegate>

Agent2 runs every delegated brief in parallel, then gives the results back to the source so it can finish. The source can delegate again, up to three rounds per request.

How API sources delegate

When the source is the Claude API or OpenAI API, it gets tools instead of tags:

ToolWhat it does
delegateSend a brief to another agent and get its result.
search_historySearch your past Markdown conversations.
composio_searchFind the right tool in your linked apps.
composio_executeRun that tool, after showing you a draft for anything that sends or posts.

Choosing who can be delegated to

In Settings → Agents you can turn delegation off entirely, or untick individual agents. Desktop apps are never delegated to, because they can't run in the background.

Writing good briefs

The source is told that each delegated agent starts with no context, so briefs are written to be complete: the goal, the files or folder, and what to report back.
