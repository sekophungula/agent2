With screen control on, your source agent can see and use the apps on your Mac: open them, click, type, scroll and point at things. You watch its cursor move while it works, and Agent2 tells you out loud what it did.

Agent2 does this with Cua Driver, an open-source tool (MIT) from Cua that runs on your Mac. It doesn't call any AI model itself: your own Claude Code or Codex does the thinking, so there's no extra account or cost.

Set it up

  1. Install Cua Driver once, in Terminal: 
    /bin/bash -c "$(curl -fsSL https://cua.ai/driver/install.sh)" -- --no-connect
    --no-connect leaves your Claude Code, Codex and Cursor settings alone; Agent2 attaches Cua Driver itself, only for its own requests.
  2. In Agent2, open Settings → Agents → Screen control and click Grant. Turn on Cua Driver under Accessibility and Screen Recording in System Settings.
  3. Make sure Let the source agent use the mouse and keyboard is ticked. It's on by default once Cua Driver is installed.

Screen control works when the source is Claude Code or Codex.

Things to ask

You sayWhat happens
“Open Notes and start a shopping list with milk and eggs.”Your agent opens Notes, makes the note and types the list.
“Show me where the Wi-Fi settings are.”It opens System Settings and moves its cursor to Wi-Fi, without clicking.
“What's in the window I have open?”It reads the window and tells you.

Safety

  • Agent2 tells the agent never to type passwords, payment details or one-time codes, and to ask you before sending, buying, posting or deleting anything.
  • Cua Driver runs in its standard mode, which refuses macOS security prompts such as password sheets.
  • Turn screen control off any time in Settings → Agents. To remove Cua Driver completely: 
    /bin/bash -c "$(curl -fsSL https://cua.ai/driver/uninstall.sh)"
  • Cua Driver sends Cua anonymous usage statistics by default (no prompts, screen contents or file paths). Turn that off with cua-driver telemetry disable.
