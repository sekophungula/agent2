Updates from inside Agent2

Version 0.1.5
  • Agent2 checks GitHub for a new version shortly after it starts and every six hours. When there is one, a green Update strip appears at the top of the chat.
  • One click downloads the update, swaps it in and reopens Agent2. Your settings, history and voice stay as they are. No more downloading from the website.
  • Also in Settings → About → Updates and in the menu (Check for updates…), with the release notes and an option to turn automatic checks off.
  • Releases are now signed with Agent2's own certificate, so macOS keeps the ⌃⌥ Accessibility permission after an update. Agent2 only installs updates signed with that certificate.
  • Coming from 0.1.4 or earlier? Download this version once from the website. Every update after it happens inside the app. You may need to allow Accessibility once more after this install.

November 26, 2026

A natural voice, on your Mac

Version 0.1.4
  • Agent2 now speaks with Kokoro, an open-source voice model that sounds far more natural than the built-in macOS voices.
  • It runs entirely on your Mac through FluidAudio, on the Neural Engine. No cloud, no API key, no cost.
  • Replies start in about half a second: Agent2 speaks the first sentence while it prepares the rest.
  • The voice is a one-time 180 MB download. It starts the first time Agent2 answers out loud, or from Settings → Voice & hotkey → Voice. Until it's ready, Agent2 uses the macOS voice.
  • Pick from six speakers, American and British, with a Preview button. Switch back to the macOS voice any time.
  • Settings → About now explains how to allow Agent2 if macOS blocks it.

November 22, 2026

Hands-free voice that talks back

Version 0.1.3
  • Hold ⌃ ⌥ and talk: no window opens. Agent2 does the job and tells you out loud what it did.
  • On MacBooks with a notch, Agent2 lives in the notch. Elsewhere it stays in the menu bar.
  • While Agent2 listens, works or speaks, the notch or menu bar icon grows into a green pill with live bars.
  • Replies are now short reports of what was done, without tables or long explanations. Long results are saved as files in your workspace.
  • Talk over Agent2, or click the pill, to stop it speaking.
  • The download is a disk image with a branded window: drag Agent2 onto Applications.
  • New in Settings → Voice & hotkey: where Agent2 lives, and whether it answers out loud.

November 22, 2026

First release

Version 0.1.0
  • Agent2 lives in the menu bar as a pixel bird. Click it for the chat, or right-click to switch source.
  • Hold ⌃ ⌥ anywhere to talk. Speech is transcribed on your Mac. A quick tap opens the chat for typing.
  • Finds Claude Code, Codex, Gemini, Cursor Agent and OpenCode, Anthropic and OpenAI API keys, and the Claude and ChatGPT desktop apps.
  • The source agent can delegate work to other agents, which run in parallel. Agent2 allows up to three follow-up rounds.
  • Conversations are saved as Markdown in ~/Agent2/History, independent of any agent.
  • Composio: sign in, link apps and add Composio to Claude Code and Codex from Settings → Apps.
  • Three autonomy levels: ask first, edit files in the workspace, or full access.
