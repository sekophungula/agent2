Install

Three steps the first time.

  1. 1

    Open the disk image and drag

    Open Agent2.dmg and drag Agent2 onto the Applications folder beside it.

  2. 2

    Open it once with right-click

    Early builds aren't notarised yet. Right-click Agent2 → Open → Open. After that it opens normally.

  3. 3

    Allow the shortcut and microphone

    Grant Accessibility for ⌃⌥, plus Microphone and Speech Recognition for voice. Full install guide →

Have an agent ready

Agent2 uses agents you already have. Install at least one.

Claude Codenpm i -g @anthropic-ai/claude-code && claude
Codex CLInpm i -g @openai/codex && codex

To link apps, also install the Composio CLI → Or skip the CLIs and add an Anthropic or OpenAI API key in Settings → Agents. API keys →
